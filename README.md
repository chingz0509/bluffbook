# BluffBook

BluffBook 是一个面向朋友娱乐局的手机端德州扑克记账网页应用。

它的目标不是做复杂的财务软件，而是在牌局现场快速记录买入、补码、结账和历史盈亏。

## 在线访问

- 统一入口：[https://bluff.chengzhuo.work/](https://bluff.chengzhuo.work/)

群友可以直接报名、取消自己的报名并实时查看本局。记账员点击页面顶部的“进入记账”，输入管理员单独配置的口令后进入记账员模式；再次点击顶部状态可以退出。

## 功能

- 报名凑局，满 5 人提示可以开局
- 报名名单通过 Vercel + Upstash Redis 共享
- 只有报名本人当前设备可以取消自己的报名
- 本局买入、离桌和结账数据在所有设备上实时查看
- 只有通过口令验证的记账员设备可以开局和修改本局
- 添加玩家，默认买入 200
- 快捷补码：+200、+400、-200
- 自动统计本局总买入
- 结账时录入每位玩家最终剩余筹码
- 自动计算每个人输赢
- 平账后生成最少转账建议
- 账目结清后存入共享历史
- 所有设备共享月度盈利排行榜
- 历史牌局可展开查看详情
- 顶部公共牌发牌动画和粒子效果

## 使用流程

1. 打开页面，进入 `报名`
2. 玩家输入姓名并点击 `我要报名`
3. 凑够 5 人后，记账员登录并点击 `开局`
4. 系统自动把报名名单带入 `本局`，每人默认买入 200
5. 牌局中只记录买入、补码和提前离桌
6. 结束后进入 `结账`
7. 录入每个人剩余筹码
8. 平账后点击 `账目结清`
9. 当前局自动进入 `历史`，并计入月度排行榜

## 本地运行

这个项目是纯前端静态页面，不需要安装依赖。

直接打开：

```bash
open index.html
```

或启动本地静态服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## 数据存储

当前版本的数据分两类：

- `报名`：线上共享，使用 Vercel API + Upstash Redis 保存。群友打开同一个链接可以看到同一份报名名单。
- `本局 / 结账`：线上共享，同样使用 Vercel API + Upstash Redis 保存；普通用户约每 4 秒自动刷新一次。
- `历史 / 月度排行`：线上共享并保存到 Upstash Redis，同时在浏览器保留本地副本。

这意味着当前版本：

- 报名名单可以多人共享
- 报名本人设备会保存一个本地凭证，用来取消自己的报名；其他人只能查看
- 记账员口令仅配置在 Vercel 环境变量中，不会写入公开网页代码
- 记账员设备验证成功后会保存一个本地凭证；后端会拒绝其他设备修改本局或清空报名
- 所有人都能实时查看本局和结账进度
- 换手机或换浏览器后，历史和月度排行仍会自动同步

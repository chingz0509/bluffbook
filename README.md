# BluffBook

BluffBook 是一个面向朋友娱乐局的手机端德州扑克记账网页应用。

它的目标不是做复杂的财务软件，而是在牌局现场快速记录买入、补码、结账和历史盈亏。

## 功能

- 添加玩家，默认买入 200
- 快捷补码：+200、+400、-200
- 自动统计本局总买入
- 结账时录入每位玩家最终剩余筹码
- 自动计算每个人输赢
- 平账后生成最少转账建议
- 账目结清后存入历史
- 月度盈利排行榜
- 历史牌局可展开查看详情
- 顶部公共牌发牌动画和粒子效果

## 使用流程

1. 打开页面，进入 `本局`
2. 添加玩家姓名
3. 牌局中只记录买入和补码
4. 结束后进入 `结账`
5. 录入每个人剩余筹码
6. 平账后点击 `账目结清`
7. 当前局自动进入 `历史`，并计入月度排行榜

## 本地运行

这个项目是纯前端静态页面，不需要安装依赖。

直接打开：

```bash
open index.html
```

或启动本地静态服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## 数据存储

当前版本使用浏览器 `localStorage` 保存数据。

这意味着：

- 刷新页面不会丢数据
- 关闭浏览器后再打开仍可保留
- 换手机、换浏览器、清理浏览器数据后不会自动同步

## 后续方向

如果要让所有玩家扫码查看、只有一个人能记账，建议后续接入 Supabase 或 Firebase：

- 创建房间码
- 玩家使用只读链接查看
- 记账员使用管理链接编辑
- 后端校验管理 token
- 所有人实时同步牌局数据

# BluffBook

BluffBook 是一个面向朋友娱乐局的手机端德州扑克记账网页应用。

它的目标不是做复杂的财务软件，而是在牌局现场快速记录买入、补码、结账和历史盈亏。

## 在线访问

[https://bluff.chengzhuo.work/](https://bluff.chengzhuo.work/)

## 功能

- 报名凑局，满 5 人提示可以开局
- 报名名单通过 Vercel + Upstash Redis 共享
- 添加玩家，默认买入 200
- 快捷补码：+200、+400、-200
- 自动统计本局总买入
- 结账时录入每位玩家最终剩余筹码
- 自动计算每个人输赢
- 平账后生成最少转账建议
- 账目结清后存入历史
- 月度盈利排行榜
- 历史牌局可展开查看详情
- 顶部公共牌发牌动画和粒子效果

## 使用流程

1. 打开页面，进入 `报名`
2. 玩家输入姓名并点击 `我要报名`
3. 凑够 5 人后，由记账员点击 `开局`
4. 系统自动把报名名单带入 `本局`，每人默认买入 200
5. 牌局中只记录买入、补码和提前离桌
6. 结束后进入 `结账`
7. 录入每个人剩余筹码
8. 平账后点击 `账目结清`
9. 当前局自动进入 `历史`，并计入月度排行榜

## 本地运行

这个项目是纯前端静态页面，不需要安装依赖。

直接打开：

```bash
open index.html
```

或启动本地静态服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## 数据存储

当前版本的数据分两类：

- `报名`：线上共享，使用 Vercel API + Upstash Redis 保存。群友打开同一个链接可以看到同一份报名名单。
- `本局 / 结账 / 历史`：暂时保存在记账员当前浏览器的 `localStorage`。

这意味着当前版本：

- 报名名单可以多人共享
- 记账和历史在当前设备上刷新不会丢
- 换手机、换浏览器、清理浏览器数据后，本局和历史不会自动同步

## 后续方向

如果要让所有玩家扫码查看牌局、只有一个人能记账，后续可以继续把本局和历史也接入后端：

- 创建房间码
- 玩家使用只读链接查看
- 记账员使用管理链接编辑
- 后端校验管理 token
- 所有人实时同步牌局数据
